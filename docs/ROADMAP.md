# 后续研究接入顺序

1. 使用 1 条已知来源、固定晶胞且已经平衡的真实轨迹验证原子身份、单位、帧间隔、PBC 与 MSD。
2. 将真实轨迹的 MSD 与引擎/OVITO/独立实现交叉核对，检查框架漂移、扩散区间和采样收敛。
3. 增加按独立轨迹/温度/体系的划分、分块 bootstrap 和多随机种子，锁定测试集。
4. 增加局域邻域特征、Li 跳跃/驻留事件、RDF/配位数，再比较时序模型与简单基线。
5. 真实数据量足够后比较 Transformer；先验证一步误差是否关联跳跃统计和长时间输运量。
6. 对齐 LAMMPS、DFTB+、VASP、CP2K 的体系与热力学设置，再研究引擎差异/多保真融合。

VASP 可用作验证来源；仓库不附带 VASP 程序、POTCAR、SK 参数或未授权轨迹。
本版不运行上述四种模拟引擎，不提供经科学验证的电解质计算输入。
